# 儿童作业奖励抽奖系统

一个专为儿童设计的作业奖励抽奖应用，通过趣味性的刮刮乐游戏激励孩子完成作业。

## 🎯 功能特色

### 核心功能
- **刮刮乐抽奖**：互动式刮刮乐体验，增加抽奖趣味性
- **作业确认机制**：确保孩子真正完成作业后才能抽奖
- **智能概率配置**：家长可灵活调整各奖项的中奖概率
- **历史记录追踪**：记录所有抽奖历史，了解孩子的奖励情况

### 技术特点
- **纯前端实现**：无需服务器，直接在浏览器中运行
- **响应式设计**：完美适配手机、平板和电脑
- **本地数据存储**：使用localStorage保存配置和历史
- **无框架依赖**：原生JavaScript开发，加载速度快

## 🎮 使用方法

### 基本操作
1. **开始抽奖**：点击"开始抽奖"按钮
2. **确认作业**：在弹出的对话框中确认作业已完成
3. **刮开卡片**：用鼠标或手指刮开覆盖层查看中奖结果
4. **查看历史**：在页面底部查看抽奖历史记录

### 家长设置
1. **进入设置**：长按或双击页面底部版权文字
2. **调整概率**：通过滑块调整各奖项的中奖概率
3. **保存配置**：点击"保存设置"应用新的概率配置
4. **重置默认**：可随时恢复到默认的概率设置

## 🌐 GitHub Pages 部署

### 部署步骤

1. **创建GitHub仓库**
   - 在GitHub上创建新仓库
   - 将项目代码推送到仓库

2. **启用Pages服务**
   - 进入仓库的Settings页面
   - 找到Pages选项
   - 选择Source为"Deploy from a branch"
   - 选择分支为main，文件夹为/root
   - 点击Save

3. **访问部署的网站**
   - 等待几分钟后
   - 访问 `https://username.github.io/repository-name`

### 自定义域名（可选）

1. **准备域名**
   - 在域名提供商处配置DNS
   - 添加CNAME记录指向 `username.github.io`

2. **在GitHub中设置**
   - 在Pages设置中添加自定义域名
   - 在仓库根目录创建CNAME文件
   - 文件内容为你的域名

### 常见问题

**Q: 刮刮乐无法正常显示？**
A: 检查浏览器是否支持Canvas，确保JavaScript文件正确加载。

**Q: 设置无法保存？**
A: 检查浏览器是否允许使用localStorage，尝试清理浏览器缓存。

**Q: 移动端体验不佳？**
A: 确保使用现代浏览器，建议使用Chrome、Safari或Edge的最新版本。
